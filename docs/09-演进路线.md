# 智枢·智能体平台 演进路线与已知问题

版本 V2.3 · 2026-09-05

> 从 demo 到可用的差距不在功能数量，而在"能不能被真实系统稳定调用、出了问题能不能看见"。
> 本文档按优先级列出改进项与已知问题，完成一项就把状态改掉并写日期；新发现的问题追加到第 4 节。

> 差距补齐批次（入口限流 / IP 管控 / 模型熔断 / Prompt 模板 / 并行节点 / 工具参数 schema / 摘要持久化 / Rerank / 轻量多租户）的需求见 `11-差距补齐PRD.md`，执行拆分与进度见 `12-差距补齐开发计划.md`。本文档中被纳入该计划的条目在状态列注明步骤号，完成后两边同批更新。

| 定时任务在多实例重复触发 | 共享库 + 多进程 | 单实例或加分布式锁 |

## 5. 明确不做的事（在有真实调用方之前）

- 接入 MCP。
- 拆微服务。
- 完整多租户（租户配额计量、企业 SSO、细粒度资源授权）。轻量隔离骨架只在满足 `12` 第三阶段列出的触发条件后才启动。
