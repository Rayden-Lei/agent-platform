# 智枢·智能体平台 演进路线与已知问题

版本 V2.1 · 2026-09-04

> 从 demo 到可用的差距不在功能数量，而在"能不能被真实系统稳定调用、出了问题能不能看见"。
> 本文档按优先级列出改进项与已知问题，完成一项就把状态改掉并写日期；新发现的问题追加到第 4 节。

## 1. 第一梯队：让它能被真实系统用起来

| 项 | 说明 | 状态 |
|---|---|---|
| 运行记录收尾 | 统一 `create_run / finalize_run`；定时任务传 thread_id；对话中断收尾；历史脏数据清理 | 完成 2026-09-04 |
| API Key 鉴权（FR-021） | `Authorization: Bearer ak_...` 分流、按归属用户执行、原子扣配额、`key_hash` 索引；契约见 `04-接口设计.md` 3.3 | 完成 2026-09-04 |
| 列表分页（FR-022） | 全部列表接口 `page / page_size` + `{items, total}`；筛选下推；运行记录页统计改接口聚合；前端 `usePagedList` 受控分页 | 完成 2026-09-04 |
| 日志与错误可见 | 请求 ID；剩余的 `except Exception` 逐个处理：能处理的处理，不能的 `logger.exception`；Redis 与 embedding 失败打 WARN 而不是静默 | 待做 |
| 降级状态可见 | 健康检查或知识库页显示"当前为 hash 向量"；文档处理时把使用的向量模型写进 `meta` | 待做 |

## 2. 第二梯队：知识库与工作流正经化

| 项 | 说明 | 状态 |
|---|---|---|
| 向量模型按知识库配置 | 模型与维度落到 `knowledge_bases` 与切片 `meta`；后台"重建索引"任务；换模型不再全局迁移 | 待做 |

| Postgres checkpointer | `langgraph-checkpoint-postgres` 替换 `MemorySaver`，人工审核跨重启可续跑 | 待做 |

## 5. 明确不做的事（在有真实调用方之前）

- 再增加节点类型或页面。
- 接入 MCP。
- 拆微服务。
- 多租户。

这些在没有真实流量之前都是给 demo 加 demo。先接一个真实场景，用真实流量逼出下一批问题。
