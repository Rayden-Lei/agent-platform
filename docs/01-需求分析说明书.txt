========================================
智枢·智能体平台 软件需求规格说明书 (SRS)
版本 V2.0（与当前实现同步）
========================================

一、引言
本文档定义智能体中台的功能与非功能需求，覆盖当前已实现的全部功能。
术语：智能体 Agent、RAG 检索增强生成、工作流 Workflow(DAG)、SSE 流式、
Token 计量、Embedding 向量化、Cron 定时。

二、项目概述
私有化部署的智能体中台，覆盖智能体的配置、运行、编排、监控、治理全生命周期。
服务内部技术/算法团队。技术栈：FastAPI + LangChain/LangGraph + PostgreSQL(pgvector) + Redis + MinIO；
前端 React + TypeScript + Ant Design + React Flow。

三、用户角色与权限
管理员 admin：全部权限（含用户/审计/API Key 管理）。
开发者 developer：创建/编辑/发布智能体、工作流、知识库、工具，运行并查看监控。
调用者 caller：仅对话调用已发布智能体。

四、功能性需求（当前已全部实现）

FR-001 登录认证 P0：用户名密码登录，JWT 签发；连续 5 次失败锁定 10 分钟（Redis 计数）。
FR-002 角色权限 P0：三级角色路由级鉴权。
FR-003 模型管理 P0：CRUD + 连通性测试 + 输入/输出单价配置（元/百万 token）。
FR-004 模型统一接入 P0：LangChain ChatOpenAI 统一封装 OpenAI 兼容厂商，流式 + token 用量。
FR-005 智能体创建 P0：数据库方式配置（名称/描述/提示词/模型/参数/知识库/工具/工作流）。
FR-006 智能体版本与发布 P0：发布生成版本号并保存配置快照；支持版本历史与一键回滚。
FR-007 对话运行时 P0：SSE 流式 + 多轮会话 + 工具调用循环 + RAG 检索注入；
     支持停止生成、重新生成、实时 token 展示、引用来源回填。
FR-008 工具调用 P0：内置工具（时间/计算器）+ 自定义 HTTP 工具。
FR-009 知识库管理 P0：创建知识库，配置切片参数。
FR-010 文档处理 P0：上传 PDF/Word/MD/TXT，异步解析切片；真实向量化（智谱 embedding-3，2048 维）。
FR-011 检索增强 P0：pgvector 余弦相似度检索，引用来源回填。
FR-012 工作流可视化编排 P0：React Flow 拖拽，5 类节点（开始/结束/智能体/工具/条件）。
FR-013 工作流运行 P0：LangGraph 执行，节点级日志（run_nodes）。
FR-014 工具管理 P0：CRUD + 测试调用。
FR-015 运行监控 P0：运行记录、token 用量、成本计算（按模型单价）。
FR-016 审计日志 P0：记录登录/资源增删改发布等操作，管理员可查。
FR-017 API Key 管理 P1：生成（明文仅显示一次）/列表/启用禁用/删除，配额与用量记录。
FR-018 定时调度 P1：APScheduler 按 Cron 定时触发工作流。
FR-019 自动化测试 P1：pytest 12 用例覆盖核心接口。
FR-020 CI/CD P1：GitHub Actions 自动跑后端测试 + 前端类型检查与构建。

五、非功能性需求
NFR-001 性能：50 并发；首字延迟 TTFT <3s（不含模型延迟）。
NFR-002 安全：bcrypt 密码、AES 密钥加密、JWT、登录限流、审计、日志脱敏。
NFR-003 部署：Docker Compose 一键私有化，数据卷持久化。
NFR-004 可用性：启动自动建表 + 初始化管理员；文档处理/定时任务异步。
NFR-005 可维护性：分层结构 + pytest + CI。
NFR-006 可扩展性：模型/工具/节点插件化；数据库为唯一配置源。

六、验收标准
AC-001 登录正常，三角色权限隔离，连续 5 次失败锁定。
AC-002 模型配置/测试/价格设置正常，token 与成本统计准确。
AC-003 智能体发布产生版本快照，可回滚到历史版本。
AC-004 对话流式、多轮、工具调用、RAG 引用、停止/重新生成均正常，实时显示 token。
AC-005 上传文档可检索（真实向量），引用来源正确。
AC-006 工作流拖拽编排并执行，含条件分支，节点日志完整。
AC-007 审计日志记录操作，API Key 可生成管理，定时任务可触发工作流。
AC-008 pytest 全部通过，Docker Compose 干净环境一键拉起。
