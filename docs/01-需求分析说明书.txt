========================================
智能体中台 软件需求规格说明书 (SRS)
版本 V1.0
========================================

一、引言
1.1 目的
本文档定义智能体中台的功能与非功能需求，作为架构设计、数据库设计、开发与测试的依据。
1.2 范围
覆盖认证与权限、模型管理、智能体管理、对话运行时、工具管理、知识库 RAG、工作流编排、运行监控八个模块。
1.3 术语
智能体 Agent：基于大模型、可调用工具/知识库/工作流完成任务的程序单元。
RAG：检索增强生成，先检索知识库再把结果交给模型生成。
工作流 Workflow：由节点和连线组成的有向无环图（DAG）编排。

二、项目概述
2.1 背景
公司内部需要统一管理多个大模型智能体，沉淀可复用能力，供技术与算法团队快速搭建、运行和编排智能体。
2.2 目标
搭建私有化部署的智能体中台，覆盖智能体的配置、运行、编排、监控全生命周期。
2.3 成功标准
技术/算法团队能自助创建、发布、运行智能体与工作流，并在真实内部场景稳定试用。

三、用户角色与权限
角色一 管理员 admin：全部权限，含用户管理、模型配置。
角色二 开发者 developer：创建/编辑/发布智能体、工作流、知识库、工具，运行并查看监控。
角色三 调用者 caller：仅可对话调用已发布智能体/工作流，查看自己的会话历史。

四、功能性需求
编号 名称 优先级 描述

FR-001 登录认证 P0
用户名密码登录，签发 JWT，支持超时失效与登出。

FR-002 角色权限 P0
按管理员/开发者/调用者三级角色控制功能与数据访问。

FR-003 模型管理 P0
模型配置增删改查；配置提供商、API 地址、密钥、模型名、默认参数；支持连通性测试。

FR-004 模型统一接入 P0
统一封装国产与国外多家模型，屏蔽接口差异，支持流式输出。

FR-005 智能体创建 P0
通过界面表单（数据库方式配置）定义智能体：名称、描述、系统提示词、模型、参数、关联知识库与工具。

FR-006 智能体版本与发布 P0
支持草稿/已发布/已停用状态，发布时生成版本号。

FR-007 对话运行时 P0
与已发布智能体对话，SSE 流式返回，多轮会话记忆，保留历史消息。

FR-008 工具调用 P0
智能体可调用内置工具与自定义 HTTP 工具，返回结构化结果。

FR-009 知识库管理 P0
创建知识库，配置切片参数与向量化模型。

FR-010 文档处理 P0
上传文档，解析 PDF/Word/Markdown/TXT，切片，向量化入库，状态跟踪。

FR-011 检索增强 P0
对话中检索知识库，把引用来源回填到回答。

FR-012 工作流可视化编排 P0
拖拽方式编排 DAG；节点类型含开始/结束/智能体/工具/条件/循环。

FR-013 工作流运行 P0
执行工作流，查看运行历史与节点级日志。

FR-014 工具管理 P0
内置工具与 HTTP 工具的增删改查与测试。

FR-015 运行监控 P2
查看运行记录、状态、耗时、token 用量与成本统计。

五、非功能性需求
NFR-001 性能：支持 50 并发调用；对话首字延迟 TTFT 平均小于 3 秒（不含模型自身延迟）。
NFR-002 安全：密码哈希存储；模型密钥加密存储；JWT 鉴权；接口访问控制。
NFR-003 部署：Docker Compose 一键私有化部署，无外部依赖。
NFR-004 可用性：单机可运行；服务重启数据不丢失，任务状态可恢复。
NFR-005 可维护性：Python + FastAPI 标准结构，模块清晰，日志完善。
NFR-006 可扩展性：模型层、工具层、工作流节点支持插件式扩展。

六、约束与假设
6.1 约束
后端 Python + FastAPI；前端 React + TypeScript；数据库 PostgreSQL + pgvector；缓存 Redis；对象存储 MinIO；工作流拖拽 React Flow；私有化部署。
6.2 假设
PostgreSQL/Redis/MinIO 现成可用；并发为几十级，不要求水平扩展。

七、版本规划
V1.0 MVP：FR-001 至 FR-014（认证、权限、模型、智能体、对话、工具调用、知识库 RAG、工作流编排与运行）。
V1.1：FR-015 监控统计、评估评测、审计日志、模型路由与降级。

八、验收标准
AC-001 登录正常，三角色权限隔离正确。
AC-002 至少配置并测试通过一家国产与一家国外模型。
AC-003 可创建并发布智能体，流式对话与工具调用正常。
AC-004 可拖拽编排并成功执行一个含条件分支的工作流。
AC-005 上传文档后可检索，回答中正确返回引用来源。
AC-006 Docker Compose 在干净环境一键拉起并可用。
