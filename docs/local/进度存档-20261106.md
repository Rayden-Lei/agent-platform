## 二、已拍板的决定（不要推翻，要改先问）

**用户明确定的**
1. 模型对话与智能体对话**并列**，都是主对话类型。
2. 工作流对话只做**方案 c**：每轮独立 run，会话只做历史展示。
3. 工具是「手」、模板是「人设」、技能是「操作手册」。
4. **技能正文不进发布快照**（只存 skill_ids）：改技能立刻对线上生效，与知识库文档同口径，**与提示词模板相反**。
5. MCP 首版：只支持 HTTP / SSE，不做 stdio、不做 OAuth、每次调用新建连接。
6. 提交粒度：**按功能域多拆**。
7. 沙箱用 **bubblewrap**（不是 nsjail / firejail / 自己写 unshare），探测失败自动降级。
8. 本地不留垃圾；项目文档里过期的环境信息（旧服务器 IP、失效凭据）必须同步更新。

**实施中定下的取舍**
- 模型对话 / 工作流对话只对 admin/developer 开放、只认 JWT；caller 只看到智能体对话。
- 技能目录**只列非 always_on 的技能**（常驻的正文已在提示词里，再列会让模型多调一次工具）。
- `load_skill` / `run_skill_script` 的白名单在**装配时**用闭包定死，执行时不查库、不按名字全局搜。
- 首版技能资源**只收 .py**（沙箱按 python 起进程，收 shell 等于给了一个没按 shell 加固的口子）。
- 沙箱降级时**只在 Linux 上进 degraded 横幅**；macOS 本机开发永远降级，进横幅只是噪音。

## 五、踩过的坑（每次都踩，务必看）

```bash
# 本机跑后端测试（连云端依赖，约 14 分钟，必须带口令，且先清登录锁）
cd /Users/lei/ai/model-platform/agent-platform/backend
ENV_FILE=.env.local .venv/bin/python -c "from app.core import redis_client; r=redis_client.get_redis(); [r.delete(k) for k in r.keys('login_fail:*')]"
ENV_FILE=.env.local TEST_ADMIN_PASSWORD='Agent-2026-Kx7m' .venv/bin/python -m pytest tests -q

# 前端类型检查
cd ../frontend && npx tsc --noEmit
```

**测试与环境**
- **清登录锁**：不清就跑全量，会出现一批 `assert 429 == 200` 假失败。这是 Redis 里 `login_fail:admin` 的残留。
- **pytest 必须指定 `tests`**：直接 `pytest` 会把 `backend/scripts/*.py` 当测试收集并报错。
- **`.env.local` 里的 TEST_ADMIN_PASSWORD 是旧口令**，命令行必须显式传 `Agent-2026-Kx7m`。
- **本机跑测试会直接写云端开发库**，没有独立测试库。测试数据带 `pytest-` 前缀，会话结束由 `tests/cleanup.py` 兜底回收。
- **conversations 有互斥约束**：单元用例不能造裸会话，用 `tests/fakes.seed_conversation`。
- **对象存储测试一律打桩**：MinIO 本机经隧道可连，但用例里打桩更快也更稳（`tests/test_kb_upload.py` 与 `test_skill_resource.py` 都是这个写法）。
- **fixture 依赖顺序**：删技能会连带清对象存储，造技能的 fixture 必须声明依赖打桩 fixture，否则 teardown 打到真 MinIO 上白等 5 秒超时。

**沙箱**
- **`/bin` 是符号链接**（Ubuntu 24.04：`/bin -> usr/bin`）。对它做 `--ro-bind` 会静默得到空目录，然后 `execvp` 报 `No such file`。要对符号链接用 `--symlink`。
- **venv 的 python 是符号链接**：用 `realpath` 推导要挂的目录会解析回 `/usr/bin/python3.x`，判定「在 /usr 下不用挂」，沙箱里找不到解释器。要用 `abspath`。
- **macOS 的 `RLIMIT_AS` 不可用**：设了会让 preexec 抛异常。降级路径限不了内存，这是平台限制不是遗漏。
- **用 root 测 bwrap 会误判**：AppArmor 对 root 不生效。线上后端现在就是 root 跑的，换非 root 账号前要用那个账号重新验证。
- **限额由子进程的引导程序自己设，不用 `preexec_fn`**：Python 文档明确写了它在多线程进程里不安全（fork 与 exec 之间可能死锁）。

**其它**
- **加快照字段会炸历史迁移脚本**：P2 加 `skill_ids` 时，`scripts/migrations/20260925_*.py` 里的 `snapshot_of(SimpleNamespace(**row))` 直接 AttributeError。**新增快照字段后 grep 一遍 `snapshot_of(` 的调用点**。
- **`git push -q` 会静默失败**：返回 0 但远端没更新（本地多了别人的提交导致远端拒绝，-q 把报错吞了）。**推送后必须核对 `git ls-remote origin main` 与本地 HEAD**。
- **多会话并行**：同一工作区可能有别的会话在改。`git add` 要**精确列文件**，别 `git add -A`；提交前 `git show --stat` 核对。
- **提交信息里有引号/反引号**：写进临时文件用 `git commit -F`，**用完立刻删临时文件**。
- **本机开着 Clash（127.0.0.1:7890）**：CLI 工具不读 macOS 系统代理，`curl` 访问需代理的地址要显式带 `-x http://127.0.0.1:7890`。
- **写 bash 脚本**：中文全角标点紧跟在变量后面会让变量名解析错（`"$PORT，"` 报 unbound variable）。变量一律写 `${VAR}`。
- **服务器到 GitHub 443 不稳**：用 SSH(22) + Deploy Key。
- **前端构建内存**：必须带 `NODE_OPTIONS=--max-old-space-size=1024`，否则 vite build 吃穿 1.7G。
