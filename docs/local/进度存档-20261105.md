- 装配：常驻（always_on）正文在前、目录在后；目录**只列非 always_on 的技能**（常驻的正文已在上面，再列会让模型多调一次 load_skill）。

- `name` 按 Agent Skills 开放标准校验 `^[a-z0-9]+(-[a-z0-9]+)*$`；`content` 按 **UTF-8 字节**限 64KB（不按字符数，中文一个字 3 字节）。
- `version` 只在 name / description / content 变化时 +1。
- 导入分两步：POST /skills/parse 只解析不落库 → 前端填进弹窗 → 走正常 POST /skills 保存。**没有第二条写库路径**。

### 已完成的沙箱可行性验证（2026-11-05，在 Windows 那台的 WSL Ubuntu 24.04 上实测）

结论：**bubblewrap 方案成立**，隔离是真实有效的。逐项实测结果：

| 测什么 | 结果 |
|---|---|
| bwrap 创建命名空间 | ✅ OK |
| 网络隔离 | ✅ 连宿主 5433、本机 6379、外网 1.1.1.1 全部被挡 |
| 文件系统隔离 | ✅ 沙箱内 `/home` 不存在、`/tmp/host_secret.txt` 读不到、根目录只有 bin dev lib lib64 proc usr |
| PID 隔离 | ✅ 沙箱内可见 4 个进程，宿主可见 77 个 |
| 环境变量清空 | ✅ `/proc/self/environ` 只剩 PATH 与 PWD |
| die-with-parent | ✅ 杀 bwrap 父进程后沙箱子进程残留 0 |
| 超时强杀 | ✅ exit=137 |
| 启动开销 | ✅ 100 次 0.856s，约 8.6ms/次 |
| Debian bookworm 有包 | ✅ python:3.11-slim 里 `bubblewrap 0.12.0`，56KB，依赖只有 libc6/libcap2/libselinux1 |

**三个坑（必须处理，别踩）**：
1. **容器里跑不了**：python:3.11-slim 默认 seccomp 下 bwrap 报 `No permissions to create a new namespace`；`--cap-add SYS_ADMIN` 报 `pivot_root: Operation not permitted`；**只有 `seccomp=unconfined` 能通**。当前生产是裸机 uvicorn（部署方式 B），不受影响；将来 docker 化时要么放弃容器 seccomp 过滤，要么降级。**所以启动时要探测 + 自动降级**。
2. **macOS 设不了内存上限**：实测 `RLIMIT_AS` 在 macOS 上直接让 preexec_fn 抛异常、子进程起不来；CPU / NPROC / FSIZE 都正常。Linux 侧 RLIMIT_AS 完全正常。文档要写明 macOS 降级路径**限不了内存**，不粉饰。
3. **venv 里的 python 要额外 bind**：只 `--ro-bind /usr /usr` 时跑 `/app/.venv/bin/python` 报 No such file；要按 `sys.executable` 自动推导补 bind。

## 五、环境与踩过的坑（每次都踩，务必看）


- **清登录锁**：不清就跑全量，会出现一批 assert 429 == 200（test_auth / test_gateway_basics / test_rate_limit 假失败，单独跑又全过）。这是 Redis 里 login_fail:admin 的残留，不是代码问题。
- **pytest 必须指定 tests**：直接 pytest 会把 backend/scripts/*.py 当测试收集并报错。
- **.env.local 里的 TEST_ADMIN_PASSWORD 是旧口令**，所以命令行必须显式传 Agent-2026-Kx7m。
- **conversations 现在有互斥约束**：单元用例不能再 Conversation(user_id=..., title=...) 造裸会话（agent_id 为空会被 DB 拦）。用 tests/fakes.seed_conversation(db, user_id, title, kind)，它连带造最少的模型 + 智能体，seeded.drop(db) 整组清理。

- **多会话并行**：同一工作区可能有别的会话在改（本轮遇到过思维链那条线）。git add 要**精确列文件**，别 git add -A；提交前用 git show --stat 核对，发现无关文件就 git reset --soft HEAD~1 重来。临时脚本（_tmp_*.py）别提交。
