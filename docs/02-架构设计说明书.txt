========================================
智枢·智能体平台 架构设计说明书 (ADD)
版本 V2.0（与当前实现同步）
========================================

一、设计目标与原则
单体优先 + 内部模块化；插件化扩展（模型/工具/节点）；数据库为唯一配置源；
异步解耦（文档处理/定时任务）；安全内建（加密/哈希/JWT/限流/审计）；不重复造轮子（LangChain/LangGraph）。

二、总体架构（分层）
接入层：React 控制台、REST API、SSE 流式。
应用层：认证/模型/智能体/对话/工具/知识库/工作流/监控/审计/API Key/定时调度 11 模块。
能力层：模型网关(LangChain)、RAG 管道、工具执行器、工作流引擎(LangGraph)、会话管理器、定时调度器(APScheduler)。
数据层：PostgreSQL(pgvector)、Redis、MinIO。
基础设施：Docker Compose、GitHub Actions CI。

三、技术选型
后端 FastAPI + SQLAlchemy 2.0 + Alembic；LangChain ChatOpenAI + create_agent + LangGraph StateGraph；
pgvector 向量检索；Redis 会话/限流；MinIO 对象存储；APScheduler 定时调度；pytest 测试。
前端 React 18 + TS + Vite + Ant Design 5 + React Flow + Zustand + axios。

四、核心模块
模型网关：ChatOpenAI（OpenAI 兼容，stream_usage 提取 token）。
会话/对话：create_agent 工具调用循环 + RAG 检索注入 + SSE 流式。
工作流引擎：LangGraph StateGraph，节点执行 + run_nodes 日志。
  节点类型（8 类）：开始/结束/智能体/工具/条件/知识库检索/代码执行/HTTP请求。
  节点配置：智能体(提示词覆盖)、工具(固定参数)、知识库检索(kb+top_k)、代码(Python)、HTTP(url+method)。
RAG 管道：按文件类型差异化解析+分片，智谱 embedding-3 向量化，混合检索（见下）。
  分片策略：文本按段落 / Markdown按标题(MarkdownHeaderTextSplitter) / PDF按页 /
  Word按段落(保留标题) / 表格csv/xlsx按行(保留列名) / 图片OCR(tesseract)，均保留元数据(页码/行号/列名/标题)。
  检索：混合召回（向量 pgvector cosine + 关键词 ILIKE），加权融合(向量0.7+关键词0.3)重排。
安全：bcrypt + AES + JWT + 登录限流(Redis) + 审计日志。
调度：APScheduler BackgroundScheduler，Cron 触发工作流。

五、数据库（18 张表）
用户 users / 模型 models / 智能体 agents / 工具 tools /
知识库 knowledge_bases / 文档 documents / 切片 document_chunks(向量) /
工作流 workflows / 节点 workflow_nodes / 会话 conversations / 消息 messages /
运行 runs / 节点日志 run_nodes / 版本 agent_versions /
审计 audit_logs / API Key api_keys / 定时任务 scheduled_jobs（+ users 已数，共 17 业务表 + 基类）。

六、安全设计
密码 bcrypt；密钥 AES 加密；JWT 24h；三角色鉴权；登录限流；操作审计；日志脱敏；接口密钥不返回。

七、部署与 CI
Docker Compose 五容器（api/web/postgres/redis/minio）；后端启动自动建表+初始化管理员；
GitHub Actions：后端 pytest + 前端 tsc/build。
