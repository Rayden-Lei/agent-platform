切换只改 token，不动结构

8 套配色共用同一套组件结构，每套只是 13 个 CSS 变量不同。系统里做主题切换时，只要换 data-theme 属性，不需要任何组件改动。

玻璃是可开关的增强

玻璃靠 backdrop-filter，低端安卓机可能掉帧。做成开关后可以按设备能力自动降级：检测到不支持就关掉，退回半透明纯色，视觉损失很小。

背景有光斑才看得出玻璃

纯色底上模糊是看不出来的。所以页面底加了两个很淡的径向渐变光斑（--blob1 / --blob2），玻璃层才有东西可糊。

深色主题要多加一层

深色下玻璃容易糊成一团灰，所以深色的 --glass 透明度调到 0.6，边框用 rgba(255,255,255,.09) 提亮轮廓。
